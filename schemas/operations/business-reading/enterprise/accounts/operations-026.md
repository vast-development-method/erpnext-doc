### Rows per company

`operation_enterprise_binding_enterprise_accounts_report_consolidated_accounts_receivable_consolidated_accounts_receivable_rows_per_company`

**Inputs** companies, filters, args, engine.

**Record and data access** read “Company” via get\_all.

**Local steps**

- Set parents from dict(Platform.get\_all(“Company”, filters = mapping(“name” → list(“in”, companies)), fields = list(“name”, “parent\_company”), as\_list = true)).
- For each company in companies.
  - Set company\_filters from Platform.\_dict(filters, company = company, group\_by\_party = 0).
  - Evaluate company\_filters.pop(“companies”, no value).
  - For each row in engine(company\_filters).run(args) at 1.
    - Set tuple(row.company, row.parent\_company) from tuple(company, parents.get(company)).
    - yield row.

On ordinary fall-through the sequence ends.
