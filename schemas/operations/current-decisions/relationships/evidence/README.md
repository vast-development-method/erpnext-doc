# Declaration locations

The [identifier ranges](index.tsv) locate the source file and enclosing declaration for each currently present binding. Ranges refer to the inspected implementation identified in the [source receipt](../../../../../docs/rebuild/model/pins.json). The qualified name and occurrence distinguish repeated definitions at the same path.

The [adapter vocabulary](adapter-terms.tsv) resolves a terminology key to the exact external symbol or literal used by the inspected implementation.
