# Report catalog

This index gives paths relative to `schemas/interfaces/report-catalog/`. A filename in code type identifies a member of the [complete catalog](../../../catalog-access.md). For example, `schemas/interfaces/report-catalog/part-0001.json` is its full path inside the checkpoint.

This directory holds ordered parts of [Report catalog](../report-catalog.json). The manifest is authoritative for order, entry counts and interpretation. Read each row with the shared semantics named by the manifest.
