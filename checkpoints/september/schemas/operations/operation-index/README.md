# Operation index

This index gives paths relative to `schemas/operations/operation-index/`. A filename in code type identifies a member of the [complete catalog](../../../catalog-access.md). For example, `schemas/operations/operation-index/part-0001.json` is its full path inside the checkpoint.

This directory holds ordered parts of [Operation index](../operation-index.json). The manifest is authoritative for order, entry counts and interpretation. Read each row with the shared semantics named by the manifest.
