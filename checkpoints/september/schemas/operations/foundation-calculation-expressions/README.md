# Foundation calculation expressions

This index gives paths relative to `schemas/operations/foundation-calculation-expressions/`. A filename in code type identifies a member of the [complete catalog](../../../catalog-access.md). For example, `schemas/operations/foundation-calculation-expressions/part-0001.json` is its full path inside the checkpoint.

This directory holds ordered parts of [Foundation calculation expressions](../foundation-calculation-expressions.json). The manifest is authoritative for order, entry counts and interpretation. Read each row with the shared semantics named by the manifest.
