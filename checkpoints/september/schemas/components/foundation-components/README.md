# Foundation components

This index gives paths relative to `schemas/components/foundation-components/`. A filename in code type identifies a member of the [complete catalog](../../../catalog-access.md). For example, `schemas/components/foundation-components/part-0001.json` is its full path inside the checkpoint.

This directory holds ordered parts of [Foundation components](../foundation-components.json). The manifest is authoritative for order, entry counts and interpretation. Read each row with the shared semantics named by the manifest.
