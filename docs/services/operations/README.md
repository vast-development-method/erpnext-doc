# Operations

Use the purpose and its business area or narrower scope to find operations. Names describe the action and arguments independently of wire spelling. Required means that an argument must be supplied. Other arguments can be omitted; numeric and Boolean defaults appear where specified. The entry identity is the first admission boundary. A guest-eligible action can still deny a particular record or require proof of authority, and authenticated actors still need role, record and field rights. The listed effects and result alternatives record known consequences; an absent entry does not confer access, rule out later effects or establish a fixed response type.
