# Custom reports

The [structured report details](custom.json) give the controls, return layouts, source locations and available procedure identifiers. See the [reading guide](README.md) for how settings select a result.

## Audit System Hooks

Script Report. The reference record is Property Setter.

The direct return positions are get columns / get data. Named output fields constructed in this report include `hook_name`, `hook_key`, `hook_values`. The structured entry gives their enclosing conditions and builders.
