# Extension source discovery and compatibility evidence

The v14 migration guide names Healthcare (now Marley), Hospitality, Non-Profit, Education, Agriculture, HRMS, DATEV, Germany, e-commerce integrations, and the separate India Compliance service. The v15 guide adds TaxJar, Exotel, Lending, France, Webshop, Payments and Saudi localisation. Legacy Social Media and WooCommerce core features were removed. External connectors available to users today have their own versioned behavior. The source URL for **8848digital/KSA** returned 404. Independent Saudi marketplace packages have distinct identities; no successor lineage, code parity or legal certification is inferred. The dated marketplace response contained 398 unique listings. Each detail page provided its publisher, displayed supported major versions and explicitly labelled GitHub resource. 209 listed version 16. Public Git resolved the default head for 329 source URLs; the other 69 remain discovery entries with unresolved heads. The index includes the SHA-256 of the public search response. Listing support refers to the publisher’s claim; a default head may run a different major or require other apps. Fifteen curated profiles also appear by matching source repository.

The Frappe documentation hub also lists products such as Learning, Helpdesk, Insights, Builder, Wiki, Drive, Raven, Books, Gantt and Cloud. Education owns academic records and fees. Learning addresses course delivery. The desktop accounting product, charting library, hosting platform and training site are adjacent products. An actual integration needs an identified data exchange, a pinned app and a test. The marketplace is an additional discovery population that includes infrastructure, themes and independently sold apps as well as ERP modules. Private installations can contain extra site apps, external services, scripts, custom fields and policies. Inventory their installed versions and exported metadata to qualify those sites. ## Package selection

The original blueprint follows four September source archives. This companion follows the named business applications separated from ERPNext in the version 14 and 15 migration guides. It also follows the CRM product/permission bridge from the original scope and the carrier integration used by Shipment. Sixteen of seventeen named split-application repositories were inspectable. The historical KSA link was unavailable, and its profile remains open. The [marketplace snapshot](marketplace.json) separately records the public listing universe observed on 18 November 2026. Field names, choices and callable identifiers are adapter vocabulary. Implementations may use different internals.

Each source pin applies to its own app. For each named repository use its version-16 branch when available, otherwise its default branch. The manifest also records paths to the upstream license files at each commit. The recorded dependency range comes from its project manifest where declared. Hook-level requirements are captured separately. A missing range is unknown. A matching major version alone cannot establish that a combination is installable. For example, Webshop declares a Payments range, and HRMS declares lower bounds for both ERPNext and Frappe. Runtime installation of the full combination has not been exercised.
