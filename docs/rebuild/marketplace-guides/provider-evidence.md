# Evidence boundaries for optional workflows

Each row identifies the strongest material in the [69-profile catalog](coverage.json), one unresolved product-specific decision and the record that would resolve it. A source copy supports the inspected revision. A manual supports the described workflow. A protocol specification supports the remote interface. The linked business chapter defines the independent implementation and its acceptance cases.

Digital Signature and Green Checklist have direct descriptions from their respective publishers. The related products described by those publishers have separate workflows. See the [signing evidence](apps/dsc.md) and [inspection evidence](apps/green_checklist.md) for the scope of that material.
